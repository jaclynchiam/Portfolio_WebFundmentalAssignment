# 🌐 Jaclyn Chiam - Personal Portfolio Website

This is my personal portfolio website, built as part of my Web Fundamentals assignment at Sunway University. It showcases who I am, my technical skills, and the personal/academic projects I've worked on so far as a first-year Computer Science student.

The website was designed and developed entirely from scratch, including the layout, user interface, and source code. I designed the UI/UX interface of the website using Figma and implemented it using HTML, CSS, and JavaScript. No AI tools were used to generate any part of this project, as it was intended to strengthen my front-end development and UI design skills through hands-on learning.


---

## ✨ Features

- Responsive grid-based layout (top nav, left icon nav, main content, footer) used consistently across all pages
- Fade-in scroll animations for a smoother browsing experience
- Interactive project cards that link out to individual project detail pages
- Skill progress bars / percentage indicators for my technical skills
- Downloadable resume accessible from the top nav on every page
- Social links (Instagram, LinkedIn, WhatsApp, Facebook, GitHub, LeetCode) in a persistent side nav
- Simple contact form for anyone who wants to reach out

---

## 🛠️ Tech Stack

- **HTML5** – page structure and content
- **CSS3** – styling, layout (Flexbox/Grid), and animations
- **JavaScript** – interactivity (page navigation, fade-in effects, form handling)
- **Google Fonts** – Inter & Inspiration fonts for typography
- **Figma** – used for UI/UX design mockups referenced in my projects

## 🚀 Running Locally

This site isn't published yet, so for now you can run it locally:

1. Clone the repo
   ```bash
   git clone https://github.com/jaclynchiam/Portfolio_WebFundmentalAssignment.git
   ```
2. Open `index.html` directly in your browser, or use a live server extension (e.g. VS Code's Live Server) for the best experience with relative paths and fonts loading properly.
